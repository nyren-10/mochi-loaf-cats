# 🐱 Mochi Loaf Cats — Squishy Antigravity Sandbox

An ultra-tactile, fidget-toy physics sandbox inspired by *Google Antigravity*, themed around squishy **"Mochi" Loaf Cats**.

Built with pure HTML5 Canvas, custom procedural bezier curve rendering, [Matter.js](https://brm.io/matter-js/) 2D physics, and native Web Audio API sound synthesis.

---

## ✨ Features

- **Procedural Living Cats:** 5 distinct varieties (Cream & Calico, Ginger Tabby, Tuxedo, Siamese Point, Peach Mochi) drawn dynamically with plush bezier curves, reactive eye pupils that follow your cursor, and expressive emotion states.
- **Squishy Squash & Stretch:** Harmonic spring physics deform cats on impact with walls or each other.
- **Tactile Drag & Toss:** Left-click and drag any cat to squish, carry, drop into boxes, or fling across the screen.
- **🔴 Red Laser Pointer:** Hold Right-Click or toggle the Laser button to emit a tracking red dot. Cats wake up, wiggle their butts, and pounce!
- **📦 "If It Fits, I Sits" Cardboard Boxes:** Cats drift near boxes and get gently sucked in, loafing inside with peeking eyes. Click any cat to pop it out, or click the `✕` badge to remove the box.
- **🌿 Catnip Zoomies:** Drop fragrant herbal clouds that send cats into frantic rainbow-trail zoomies and corkscrew spins!
- **🌌 Smooth Gravity Flow:** Seamlessly cycle between Earth Gravity (`1.0G`), Zero-G Space (`0G`), Cozy Low-G Moon hops (`0.22G`), and Inverted Ceiling Float (`-0.45G`).
- **🔊 Native Web Audio Synthesizer:** Pure synthesized pentatonic collision chimes, spring boings, purr rumble, laser squeaks, and pop sound effects — zero external audio assets required.

---

## 🚀 Quick Start

Simply open `index.html` in any modern web browser, or serve it locally:

```bash
# Using Node.js
node server.js
```

Then visit `http://localhost:3001/`.
